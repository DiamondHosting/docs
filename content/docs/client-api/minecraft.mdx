## 模組包管理

<ApiBasePath>https://panel.diamondhost.tw/api/client/servers/{server}/minecraft-modpacks</ApiBasePath>

<ApiEndpoint method="GET" path="/?provider=modrinth&page=1&page_size=20&search_query=vanilla" title="搜尋模組包" description="依供應商、頁碼與關鍵字搜尋可安裝的模組包。" />
<ApiEndpoint method="GET" path="/versions?provider=modrinth&modpack_id=AANobbMI" title="取得模組包版本" description="列出指定供應商與模組包的可用版本。" />
<ApiEndpoint method="GET" path="/status" title="取得安裝狀態" description="回傳目前安裝步驟、錯誤與完成狀態。" />

<ApiEndpoint method="POST" path="/install" title="安裝模組包" description="下載指定版本；可選擇是否先刪除既有伺服器檔案。">

```json
{
  "provider": "modrinth",
  "modpack_id": "AANobbMI",
  "modpack_version_id": "3.0.2",
  "delete_server_files": false
}
```

</ApiEndpoint>

## MCLogs 日誌管理

<ApiBasePath>https://panel.diamondhost.tw/api/client/servers/{server}/mclogs</ApiBasePath>

<ApiEndpoint method="GET" path="/" title="列出已上傳日誌" description="列出伺服器先前上傳至 mclo.gs 的日誌記錄。" />
<ApiEndpoint method="GET" path="/settings" title="取得日誌設定" description="回傳每台伺服器可保留的日誌數量上限。" />
<ApiEndpoint method="GET" path="/scan" title="掃描日誌檔案" description="掃描伺服器內可供上傳的日誌檔案。" />

<ApiEndpoint method="POST" path="/upload" title="上傳日誌內容" description="將文字內容上傳至 mclo.gs，log_type 為選填分類。">

```json
{
  "content": "[Server thread/INFO]: Done (2.314s)!",
  "log_type": "latest"
}
```

</ApiEndpoint>

<ApiEndpoint method="POST" path="/upload-file" title="上傳指定日誌檔" description="讀取伺服器內指定路徑的日誌並上傳至 mclo.gs。">

```json
{ "file_path": "/logs/latest.log" }
```

</ApiEndpoint>

<ApiEndpoint method="DELETE" path="/{log}" title="刪除日誌記錄" description="刪除指定的日誌上傳記錄。" />

## 版本切換

<ApiBasePath>https://panel.diamondhost.tw/api/client/extensions/versionchanger/servers/{server}</ApiBasePath>

<ApiEndpoint method="GET" path="/installed" title="取得已安裝版本" description="回傳目前核心類型、版本與 build 資訊。" />

<ApiEndpoint method="POST" path="/install" title="安裝新版本" description="使用 build ID 安裝版本，並確認 EULA 與檔案處理方式。">

```json
{
  "build": 123,
  "delete_files": false,
  "accept_eula": true
}
```

</ApiEndpoint>

<ApiEndpoint method="GET" path="/install/status/{installation}" title="取得版本安裝狀態" description="以 installation ID 查詢安裝進度。" />
<ApiEndpoint method="GET" path="/install/latest" title="取得最近安裝記錄" description="取得最近一次版本安裝工作。" />
<ApiEndpoint method="GET" path="/types" title="列出核心類型" description="列出 Vanilla、Paper、Purpur、Forge、Fabric 等可用核心。" />
<ApiEndpoint method="GET" path="/types/{type}" title="列出核心版本" description="列出指定核心類型的可用版本。" />
<ApiEndpoint method="GET" path="/types/{type}/{version}" title="列出版本 Builds" description="列出指定核心版本的可用 build。" />

## 玩家管理

<ApiBasePath>https://panel.diamondhost.tw/api/client/extensions/minecraftplayermanager/servers/{server}</ApiBasePath>

<ApiEndpoint method="GET" path="/" title="取得玩家與權限狀態" description="回傳線上玩家、OP、白名單與封鎖清單。" />
<ApiEndpoint method="GET" path="/skin" title="取得玩家皮膚頁面" description="回傳玩家管理器使用的皮膚 HTML。" />
<ApiEndpoint method="GET" path="/offline" title="列出離線玩家" description="從世界玩家資料中列出目前離線的玩家。" />
<ApiEndpoint method="GET" path="/stats/{uuid}" title="取得玩家資料" description="取得指定 UUID 的統計與 NBT 玩家資料。" />

<ApiEndpoint method="POST" path="/whitelist/status" title="切換白名單" description="啟用或停用伺服器白名單。">

```json
{ "enabled": true }
```

</ApiEndpoint>

<ApiEndpoint method="PUT" path="/whitelist" title="加入白名單" description="依 Minecraft 玩家名稱加入白名單。">

```json
{ "name": "Steve" }
```

</ApiEndpoint>

<ApiEndpoint method="DELETE" path="/whitelist" title="移出白名單" description="依玩家 UUID 從白名單移除。">

```json
{ "uuid": "8667ba71-b85a-4004-af54-457a9734eed7" }
```

</ApiEndpoint>

<ApiEndpoint method="PUT" path="/op" title="授予 OP" description="依玩家名稱授予 OP 權限。">

```json
{ "name": "Steve" }
```

</ApiEndpoint>

<ApiEndpoint method="DELETE" path="/op" title="移除 OP" description="依玩家 UUID 移除 OP 權限。">

```json
{ "uuid": "8667ba71-b85a-4004-af54-457a9734eed7" }
```

</ApiEndpoint>

<ApiEndpoint method="PUT" path="/ban" title="封鎖玩家" description="依玩家名稱封鎖並記錄原因。">

```json
{ "name": "Steve", "reason": "Griefing" }
```

</ApiEndpoint>

<ApiEndpoint method="DELETE" path="/ban" title="解除玩家封鎖" description="依玩家 UUID 解除封鎖。">

```json
{ "uuid": "8667ba71-b85a-4004-af54-457a9734eed7" }
```

</ApiEndpoint>

<ApiEndpoint method="PUT" path="/ban-ip" title="封鎖 IP" description="封鎖指定 IP，reason 為選填。">

```json
{ "ip": "203.0.113.10", "reason": "Abuse" }
```

</ApiEndpoint>

<ApiEndpoint method="DELETE" path="/ban-ip" title="解除 IP 封鎖" description="解除指定 IP 的封鎖。">

```json
{ "ip": "203.0.113.10" }
```

</ApiEndpoint>

<ApiEndpoint method="PUT" path="/ban-ip-player" title="封鎖玩家 IP" description="依玩家 UUID 封鎖該玩家使用的 IP。">

```json
{
  "uuid": "8667ba71-b85a-4004-af54-457a9734eed7",
  "reason": "Ban evasion"
}
```

</ApiEndpoint>

<ApiEndpoint method="POST" path="/kick" title="踢出玩家" description="依玩家 UUID 將線上玩家踢出伺服器。">

```json

```

</ApiEndpoint>

<ApiEndpoint method="POST" path="/kill" title="殺死玩家" description="依玩家 UUID 執行 kill。">


</ApiEndpoint>

<ApiEndpoint method="POST" path="/clear" title="清空玩家背包" description="依玩家 UUID 清除背包物品。">

```json
{ "uuid": "8667ba71-b85a-4004-af54-457a9734eed7" }
```

</ApiEndpoint>

<ApiEndpoint method="POST" path="/wipe" title="清除玩家資料" description="依玩家 UUID 清除玩家資料。">

```json
{ "uuid": "8667ba71-b85a-4004-af54-457a9734eed7" }
```

</ApiEndpoint>

<ApiEndpoint method="POST" path="/set-stat" title="設定玩家屬性" description="修改遊戲模式、經驗、位置、生命、飽食度或物品欄資料。">

</ApiEndpoint>
