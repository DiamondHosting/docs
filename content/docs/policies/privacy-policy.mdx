**捷上科技有限公司**（以下簡稱「我們」）非常重視您的隱私權。本政策旨在說明當您使用 **鑽石託管 (DiamondHost)** 網站及相關服務時，我們如何處理您的個人資料。

## 1. 我們蒐集的資料

為了提供服務、處理訂單及維護系統安全，我們會蒐集以下類型的資料：

### 1.1 帳戶資訊
- **識別資料**：註冊時提供的姓名、地址、電子郵件地址、Discord ID、手機號碼。
- **驗證資料**：為符合法規要求或防止詐欺，我們可能要求提供身分驗證文件（如在特殊爭議案件中）。

### 1.2 交易資訊
- **付款紀錄**：交易金額、日期、支付方式及發票抬頭統編。
- **注意**：我們**不會**儲存您的完整信用卡卡號。所有線上刷卡均透過合規的第三方金流平台（如 Payuni、PayPal）進行加密處理。

### 1.3 服務使用紀錄 (Log Data)
- **連線紀錄**：IP 位址、瀏覽器類型、存取時間、操作路徑。
- **伺服器日誌**：當您使用託管服務時，系統會自動記錄資源使用量（CPU/RAM）、指令操作與錯誤報告。

### 1.4 Google Drive 匯入資料

當您主動連結 Google 帳號或使用 Google Drive 檔案匯入功能時，我們會依您授予的權限處理以下資料：

- **Google 帳號資料**：Google 帳號識別碼、電子郵件地址、個人資料圖片網址、授權範圍及連結時間，用於辨識及顯示您已連結的帳號。
- **OAuth 授權資料**：我們會保存 Google 提供的 refresh token，以便在您使用匯入功能時取得短期 access token。refresh token 會加密保存；短期 access token 會提供給 Google Picker 及執行下載的伺服器節點，但不會作為帳號資料長期保存。
- **Drive 檔案資料**：當您瀏覽、搜尋或選擇檔案時，系統可能暫時處理檔案 ID、名稱、大小、MIME 類型、修改時間、縮圖或檢視連結及是否可下載等中繼資料。
- **匯入內容與紀錄**：只有您選定的檔案內容會由 Google Drive 傳輸至指定的伺服器目錄。系統另會記錄檔案 ID、檔名及目的目錄，供安全稽核與故障排除使用。

Google Drive 授權包含 `openid`、`email`、`profile` 與 `https://www.googleapis.com/auth/drive.file`。`drive.file` 用於存取您透過本服務選擇或授權本服務使用的檔案；本功能不會將整個 Google Drive 同步或備份至我們的系統。

## 2. 資料使用目的

我們僅在以下合法基礎上處理您的資料：
1. **履行合約**：開通服務、寄送帳單、提供技術支援。為健全技術知識庫及加速其他用戶之故障排除，您所提交之客服單問題將在去識別化後公開展示。
2. **法定義務**：依稅法規定開立發票、依電信法規保留連線紀錄。
3. **合法利益**：偵測詐欺訂單（Fraud Detection）、防禦網路攻擊、改善系統效能。
4. **Google Drive 匯入**：依您的指示連結 Google 帳號、顯示 Google Picker、取得所選檔案的必要資訊，並將該檔案匯入您指定的託管伺服器目錄。

## 3. 資料保存期限

我們依資料性質設定不同的保留期限，期滿後將自動刪除或匿名化處理：

| 資料類型 | 保存期限 | 說明 |
| :--- | :--- | :--- |
| **帳戶與交易資料** | 永久 / 5 年 | 依商業會計法及稅法規定，財務憑證需保留至少 5 年。 |
| **系統日誌 (Logs)** | 180 天 | 包含連線 IP 與操作紀錄，用於資安稽核與除錯。 |
| **用戶伺服器檔案** | **服務終止後 3 天** | 指您上傳至主機內的 World 存檔、插件等。過期即刪除。 |
| **客服對話紀錄** | 至少 1 年 / 永久 | 基本上保證儲存至少 1 年，在可行情況下得永久保存，用於提升服務品質、爭議查證及第三方分析優化。 |
| **Google 帳號授權資料** | 至解除連結或面板帳號刪除 | 包含帳號識別資料、授權範圍與加密保存的 refresh token。解除連結時，系統會嘗試向 Google 撤銷 token 並刪除本機授權紀錄。 |
| **Google Drive 匯入紀錄** | 180 天 | 檔案 ID、檔名與目的目錄會作為系統活動紀錄保存。匯入後的檔案視為用戶伺服器檔案，適用相同保存期限。 |

瀏覽與搜尋 Drive 時取得的檔案清單及中繼資料不會另建永久資料庫保存；為完成匯入而取得的短期 access token 亦不會作為帳號資料長期保存。移除 Google 帳號授權不會自動刪除先前已匯入伺服器的檔案。

## 4. 資料分享與揭露

除以下情形外，我們不會將您的資料提供給第三方：
1. **服務協力廠商**：如金流服務商（處理付款）、電子郵件發送商（寄送通知），或提供客服單諮詢內容予第三方技術協同，以共同協助系統診斷與障礙排除。
2. **法律要求**：若收到法院、檢察署或警察機關之正式公文調閱（如偵辦詐欺或網路犯罪），我們將依法配合提供相關連線紀錄與註冊資料。
3. **業務轉讓**：若本公司發生合併或收購，用戶資料可能作為資產的一部分進行移轉。

使用 Google Drive 匯入時，您的瀏覽器與伺服器節點會與 Google OAuth、Google Picker 及 Google Drive API 通訊。Google 對其服務所處理資料的方式，適用 [Google 隱私權政策](https://policies.google.com/privacy)。除完成您要求的授權、選檔與匯入外，我們不會將 Google 使用者資料提供給廣告平台、資料仲介商或用於個人化廣告。

### 4.1 Google API 資料使用限制

我們使用及傳輸從 Google APIs 取得的資訊時，將遵守 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的 Limited Use 要求。Google 使用者資料僅用於提供及維護本政策所述的 Google Drive 匯入功能、保障安全，以及在必要時排除與該功能直接相關的故障。

## 5. Cookie 技術的使用

本網站使用 Cookie 來維持您的登入狀態及紀錄購物車內容。
- **必要性 Cookie**：無法關閉，否則無法使用客戶中心功能。
- **分析性 Cookie**：(如 Google Analytics) 用於分析流量概況，您可以透過瀏覽器設定拒絕。

## 6. 您的權利

依據《個人資料保護法》，您享有以下權利：
- **查詢與閱覽**：您可登入客戶中心查看您的個人資料。
- **更正與補充**：若資料有誤，請自行修正或聯繫客服。
- **刪除權**：在不違反法令保存義務（如稅務資料需留存）的前提下，您可請求刪除帳戶。
- **撤回 Google 授權**：您可在面板的「帳號設定 > Google Drive」移除個別 Google 帳號，也可從 Google 帳號的第三方應用程式連線設定撤銷存取權。撤回授權不影響撤回前處理行為的合法性，亦不會自動刪除已匯入伺服器的檔案或 Google Drive 中的原始檔案。
