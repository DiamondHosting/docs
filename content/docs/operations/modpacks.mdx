# 模組包快速安裝

我們的面板內建了模組包快速安裝功能，讓您可以輕鬆部署熱門的模組包（如 Pixelmon、RLCraft、All the Mods 等），無需手動上傳檔案。

### 安裝步驟

1. **進入模組包選單**：在左側導覽列中點選「模組包」圖示。
2. **挑選模組包與平台**：您可以瀏覽熱門模組包。點擊右上角的下拉選單，可以切換不同的模組來源，包括：
   - **CurseForge**
   - **Modrinth**
   - **FTB (Feed The Beast)**
   - **Technic** 等
3. **執行安裝**：
   - 點擊目標模組包下方的「安裝」按鈕。
   - 選擇您想要的模組包版本。
   - 如果您希望清空目前的伺服器檔案再安裝，請勾選「格式化 (Format)」相關選項。
   - 點擊「安裝」開始程序。

   > [!IMPORTANT]
   > **下載需要時間**：由於部分模組包檔案體積較大（可能包含數百個模組及地圖檔案），下載與解壓縮過程需要一段時間。請在安裝頁面稍作等待，切勿在安裝完成前關閉視窗或重啟伺服器。

### 安裝完成後

安裝完成後，伺服器會自動配置好啟動環境。您可以回到「主控台」啟動伺服器，並開始您的冒險！
