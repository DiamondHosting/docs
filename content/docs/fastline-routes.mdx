# 我們託管的路線

鑽石託管為伺服器與網站提供多條高性能網路清洗與連線路線，您可以依據連線需求與地理位置選擇適當的 CNAME 指向網域。

本頁面詳細介紹各條託管路線之特性、CNAME 對應位址與網域 DNS 解析設定步驟。

---

## CNAME 路線對應總表

以下為鑽石託管所提供的主要連線與防護路線 CNAME 對應表：

| CNAME 指向網域 | 路線名稱 | 路線說明與適用場景 |
| --- | --- | --- |
| [`server.diamondhost.tw`](http://fastline.diamondhost.tw/) | **FastLine 主線路** | 臺灣在地高防路線，低延遲且具備高速清洗能力 |
| [`cloudflare.diamondhost.tw`](http://cloudflare.diamondhost.tw/) | **Cloudflare Magic Transit** | 整合 Cloudflare 全球 Anycast 防護網路與清洗節點 |
| [`intl.diamondhost.tw`](http://intl.diamondhost.tw/) | **海外清洗路線** | 專為海外與國際流量過濾設計的節點路線 |

---

## 各路線詳細說明

### 1. 臺灣 FastLine 主線路
* **CNAME 地址**：`server.diamondhost.tw`（或 `fastline.diamondhost.tw`）
* **路線特色**：針對臺灣及亞太地區玩家優化的高防線路，提供極低連線 Ping 值與本土高速 DDoS 流量清洗能力，適合大部分玩家主要的連線入口。

### 2. Cloudflare Magic Transit 路線
* **CNAME 地址**：`cloudflare.diamondhost.tw`
* **路線特色**：結合 Cloudflare 全球 Anycast 骨幹網路。當遭遇跨國或全球分散式流量攻擊時，提供大規模 Anycast 流量吸納與防護分流。

### 3. 海外清洗路線
* **CNAME 地址**：`intl.diamondhost.tw`
* **路線特色**：海外防護與清洗節點，專門過濾源自海外的異常攻擊流量，保障伺服器在國際連線情境下的穩定度。

## 網域 CNAME / SRV 解析設定步驟

若您擁有自訂網域（例如 `myserver.com`），可依照以下步驟設定 DNS 指向鑽石託管路線：

<Steps>
<Step>
### 登入您的網域託管商控制台
登入您的網域服務商（如 Cloudflare、GoDaddy、Namecheap 等）DNS 管理頁面。
</Step>

<Step>
### 新增 CNAME 記錄
在 DNS 設定中新增一筆 CNAME 記錄：
- **名稱 (Name)**：例如 `mc` 或 `@`
- **目標 (Target / Value)**：填入 `server.diamondhost.tw`、`cloudflare.diamondhost.tw` 或 `intl.diamondhost.tw`
- **TTL**：設定為 `Auto` 或 `300` 秒
</Step>

<Step>
### (Minecraft 伺服器) 設定 SRV 記錄
若您需要自訂 Port 或隱藏連接埠，請新增一筆 SRV 記錄指向您的 CNAME 網域即可完成解析對應。
</Step>
</Steps>
