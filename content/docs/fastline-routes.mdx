## 各路線詳細介紹

### 1. 臺灣 FastLine 主線路 (保證可用)
* **CNAME 地址**：`server.diamondhost.tw`（或 `fastline.diamondhost.tw`）
* **連線品質**：**正式服務，保證連線可用性與防護品質**
* **說明**：針對臺灣本地與亞太地區進行優化的高防清洗線路，具備極低延遲與強大防護力，為購買 Fastline 抗攻擊服務的核心保障項目。

### 2. Cloudflare Magic Transit 線路 (贈送項目)
* **CNAME 地址**：`cloudflare.diamondhost.tw`
* **連線品質**：**免費贈送附加服務（不保證連線與可用性）**
* **說明**：整合 Cloudflare 全球 Anycast 骨幹網路與 Magic Transit 防護。當您的伺服器遭遇來自全球的大規模攻擊時，可作為彈性防護切換選擇。

### 3. 海外清洗線路 (贈送項目)
* **CNAME 地址**：`intl.diamondhost.tw`
* **連線品質**：**免費贈送附加服務（不保證連線與可用性）**
* **說明**：專為海外流量清洗設計的節點線路，適合處理海外來源的極端攻擊流量。

## 網域 CNAME / SRV 解析設定步驟

若您擁有自己的網域（如 `myserver.com`），可以跟著以下步驟設定 CNAME 記錄指向 Fastline 線路：

<Steps>
<Step>
### 登入您的網域託管商控制台
登入您的網域服務商（如 Cloudflare、GoDaddy、Namecheap 等）的 DNS 管理頁面。
</Step>

<Step>
### 新增 CNAME 記錄
新增一筆 CNAME 記錄：
- **名稱 (Name)**：例如 `mc` 或 `@`
- **目標 (Target / Value)**：填入 `server.diamondhost.tw`（主線路）、`cloudflare.diamondhost.tw` 或 `intl.diamondhost.tw`
- **TTL**：設定為 `Auto` 或 `300` 秒
</Step>

<Step>
### (Minecraft 伺服器) 設定 SRV 記錄
若您需要自訂 Port 或隱藏連接埠，請新增一筆 SRV 記錄指向您的 CNAME 網域即可完成對應。
</Step>
</Steps>
